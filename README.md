# 花茶 LOGO 設計與色彩美學互動學習平台

本平台是專為國小美術一日課程（共 7 節課）設計的互動式輔助教學系統。結合設計簡報、概念挑戰、調色挑戰及 LOGO 配對遊戲，幫助學生在有趣的氛圍中掌握 LOGO 設計與色彩美學。

## 課程大綱
- **第 1~2 節**：LOGO 設計理論與花草元素
- **第 3 節**：壓克力顏料與四原色基礎
- **第 4~5 節**：調色挑戰與 LOGO 起步
- **第 6~7 節**：實作發表與成品發表

## 平台功能特色
- 🏛️ **首頁大廳**：展示一日精華課程計畫與大綱。
- 📖 **簡報知識庫**：
  - 單元 1：LOGO 的本質與造形簡化學（結合大師聯想）
  - 單元 2：色彩心理學與品牌性格（結合課本色彩學）
  - 單元 3：壓克力顏料的四大專業藝術技法
  - 單元 4：四原色 CMYK 基礎與混色公式
- 📝 **概念挑戰賽**：即時答題檢驗學習成果。
- 🧪 **調色大挑戰**：互動式調色模擬器（紅、黃、藍、白、黑四原色調色）。
- 🧩 **LOGO 配對大挑戰**：配對 20 個經典 LOGO 與品牌，考驗簡化觀察力。

## 開發技術
- 核心：HTML5, JavaScript (Vanilla JS)
- 樣式：CSS3 (響應式設計、現代漸變、微動畫)
- 圖示：Font Awesome 6.4.0
- 字型：Noto Sans TC, Outfit (Google Fonts)

## 本地運行
直接在瀏覽器中開啟 `index.html` 即可運行本平台，或使用 Live Server 等本地開發伺服器啟動。
